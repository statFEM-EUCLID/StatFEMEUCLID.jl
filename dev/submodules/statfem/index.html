StatFEMEUCLID.StatFEM — Module

StatFEM

This submodule contains functions for performing the statistical FEM on given measurement data and stochastic prior. The method corrects a given PCE based prior $u_f$ based on given measurements with independent measurement noise using a Gauß-Markov Kalman Filter.
